Возможности

Всё для управления сервером

Без браузера, без лишних зависимостей, без чёрного окна cmd.

Управление сервером
Запуск, остановка и перезапуск в один клик. Корректная остановка через stop, при зависании — принудительное убийство дерева процессов.
Консоль с подсветкой
Логи Minecraft в реальном времени. Ошибки красным, варны жёлтым, успешный старт зелёным. Команды можно писать прямо в окно.
Файловый менеджер
Просмотр, редактирование, удаление, переименование. Встроенный редактор для 20+ расширений. Загрузка с ПК и скачивание папок архивом.
Автобэкапы
Сохранение в Документы с максимальным сжатием. Мусор исключается. Старые бэкапы удаляются сами — хранится 10 последних.
Темы и кастомизация
8 цветовых тем, 11 шрифтов, регулировка прозрачности панелей, свой фон из картинки (PNG/JPG/GIF/WEBP).
Кроссплатформенность
Windows (.bat, .cmd, .jar), Linux и macOS (.sh, .jar). Автовыбор команды запуска по расширению.
Звуки и уведомления
Приятный звук при запуске и остановке сервера. Тосты-уведомления о каждом действии — сохранение файла, бэкап, ошибка.
Мониторинг ресурсов
CPU, RAM и PID сервера в шапке окна. Данные берутся напрямую с процесса java.exe, а не с cmd-обёртки.
Мультиязычность
Русский и английский из коробки. Переключение прямо в настройках — интерфейс обновляется мгновенно, без перезапуска.
Туториал

Как пользоваться McPilot

Пошагово от установки до первого запуска сервера.

1
Скачай McPilot.zip
Нажми на кнопку — архив скачается с GitHub.
Скачать McPilot.zip
2
Установи Python 3.9+
Скачай с python.org. На Windows при установке поставь галочку Add Python to PATH — это важно, иначе команды не будут работать в терминале.
3
Установи зависимости
Открой терминал (cmd на Windows, Terminal на macOS/Linux) и выполни:
pip install pywebview psutil
На Linux дополнительно нужны системные пакеты: sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.0
4
Распакуй архив в папку сервера
Содержимое McPilot.zip (app.py, README.md, .gitignore) — прямо в папку твоего Minecraft-сервера, рядом с start.bat, server.jar или start.sh.
5
Первый запуск
В той же папке открой терминал и запусти:
python app.py
Откроется окно терминала с ASCII-баннером, где McPilot спросит имя файла запуска. Впиши start.bat (или server.jar, или start.sh) и нажми Enter.
6
Запусти сервер
Откроется окно McPilot. Жми зелёную кнопку «Запустить» в шапке — сервер стартует, а логи начнут сыпаться в консоль. Дождись строки Done (X.XXs)! — сервер готов принимать игроков.
7
Управляй через консоль
Внизу окна — поле ввода. Пиши любые команды Minecraft (say Привет, op Steve, list) и жми Enter. Это то же самое, что писать в консоль сервера напрямую.
8
Редактируй файлы
Справа — панель файлов. Кликай по любому текстовому файлу (server.properties, paper.yml, whitelist.json и т.д.) — он откроется в редакторе. Сохранить — Ctrl+S.
9
Делай бэкапы
Кнопка «Бэкап» в шапке. Сохранит всё в Документы, сожмёт по максимуму, выкинет логи и мусор. Старые (сверх 10) удаляются автоматически.
10
Настрой под себя
Шестерёнка в правом верхнем углу. Там можно поменять тему, шрифт, прозрачность, язык, загрузить свой фон, поменять файл запуска и настроить звуки.
FAQ

Частые вопросы

Это точно безопасно?
Да. McPilot — это открытый исходный код (лицензия MIT). Программа не делает никаких сетевых запросов, не собирает телеметрию и не имеет встроенных платежей. Ты можешь сам открыть app.py и проверить каждую строчку. Единственное, что она делает — управляет твоим сервером локально.
Сервер не запускается, что делать?
Проверь три вещи: 1) имя файла запуска введено правильно и файл существует; 2) у тебя установлен Java, и команда java -version работает в терминале; 3) путь к папке сервера не содержит пробелов и кириллицы в названиях.
Работает ли на Linux и macOS?
Да. На Linux и macOS используй .jar (запуск через java -jar) или .sh скрипт. Файлы .bat на Linux работают через wine, если он установлен, — но лучше сделать .sh.
Где хранятся бэкапы?
В папке Документы: ~/Documents/McPilotBackups/ на английской системе, ~/Документы/McPilotBackups/ на русской. На macOS — ~/Documents/McPilotBackups/. На Linux McPilot сам найдёт правильную папку.
Как поменять файл запуска после первого раза?
Открой настройки (шестерёнка в шапке) → раздел «Файл запуска» → кнопка «Выбрать». Но менять можно только при остановленном сервере.
Это точно бесплатно?
Да, полностью. Лицензия MIT — делай что хочешь, форкай, меняй, раздавай. Никаких встроенных платежей и рекламы.
