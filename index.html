mcpilot,
менеджер minecraft-серверов

консоль с подсветкой логов, редактор файлов, бэкапы, мультисервер, графики cpu и ram. работает на windows, linux и macos.

скачать как установить

версии

свежие релизы подтягиваются с github автоматически

что умеет

без браузера, без зависимостей, без чёрного cmd

мультисервер
несколько серверов в одном окне, вкладки как в браузере, у каждого свои логи, бэкапы и метрики
консоль с подсветкой
ошибки красным, варны жёлтым, успешный старт зелёным, команды пишутся прямо в окно
редактор файлов
номера строк, поиск, статус-бар, ctrl+s, поддержка 20+ расширений
графики cpu и ram
живой мониторинг за последние 3 минуты, видно утечки памяти и пики нагрузки
бэкапы
в документы, с максимальным сжатием, старые удаляются автоматически, хранится 10 последних
счётчик игроков
показывает сколько онлайн, разбирая логи, наводишь, видишь список ников
кастомные темы
импорт json-файлов от других людей, свои тоже можно делать и отдавать
кросс-платформа
windows, linux, macos, поддержка .bat, .sh и .jar файлов запуска

установка

нужен только python 3.9 или новее

1, скачай архив
нажми «скачать» в разделе версии выше
2, установи python
с python.org, при установке на windows поставь галочку add python to path
3, установи зависимости
pip install pywebview psutil
4, распакуй в папку сервера
рядом с start.bat, server.jar или start.sh
5, запусти
python app.py
первый раз спросит папку и файл запуска, запомнит

частые вопросы

это безопасно
да, исходники открыты, лицензия mit, никаких сетевых запросов, платежей и телеметрии, можно открыть app.py и проверить каждую строчку
сервер не запускается, что делать
проверь три вещи, правильное имя файла запуска, установлена java и работает java -version, путь к папке без пробелов и кириллицы
работает на linux и macos
да, на linux и macos используй .jar или .sh, .bat работает через wine, если он установлен
где хранятся бэкапы
в папке документы, на русской винде это Документы, на linux и macos mcpilot сам находит правильную папку
это бесплатно
